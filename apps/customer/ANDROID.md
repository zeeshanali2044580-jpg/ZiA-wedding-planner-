# ZIA Event and Wedding Planner — Android packaging

The customer web app is configured for Capacitor with:

- Application name: `ZIA Event and Wedding Planner`
- Application ID: `pk.zia.eventplanner`
- Web output directory: `dist`

The admin app is not included in the Android target and remains a separate private web application.

## Generate the Android project

From the repository root, after installing Node.js, the Android SDK, JDK 17, and Gradle prerequisites:

```bash
npm install
cd apps/customer
npm run build
npx cap add android
npx cap sync android
```

The `android/` directory is generated by Capacitor CLI and should then be committed if Android source is to be maintained in Git.

## Build APK/AAB

```bash
cd apps/customer
npm run android:build   # debug APK
npm run android:bundle  # release AAB
```

Expected outputs after a successful Gradle build:

```text
apps/customer/android/app/build/outputs/apk/debug/app-debug.apk
apps/customer/android/app/build/outputs/bundle/release/app-release.aab
```

This repository configuration does not include signing credentials. A release AAB requires a locally configured signing key and Android signing configuration.
