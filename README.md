# ZIA Business Platform

This repository contains exactly two app frontends:

- apps/customer — ZIA Customer App
- apps/admin — ZIA Private Admin Panel

## Stack

- React + Vite
- Modern mobile-first UI
- PKR currency styling and brand system

## Run locally

```bash
npm install
npm run dev:customer
npm run dev:admin
```

## Files

- `apps/customer` contains the public customer experience only.
- `apps/admin` contains the private business operations dashboard.
- `supabase/schema.sql` contains starter database schema for weddings, electronics, orders, and admin access.

## Brand

- Brand: ZIA
- Business lines: Wedding & Event Planner and ZIA Electronics
- Currency: PKR (₨)
